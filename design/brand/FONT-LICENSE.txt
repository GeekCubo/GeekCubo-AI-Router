Inter typeface — SIL Open Font License 1.1
==========================================

The GeekCubo wordmark ("GeekCubo") and Open Graph artwork use OUTLINED glyphs
from the Inter typeface (Rasmus Andersson), converted to vector paths at build
time. No font file is shipped; only the rendered outlines are embedded in the
SVG/PNG assets generated by scripts/brand/build_brand.py.

Inter is distributed under the SIL Open Font License, Version 1.1, which
permits embedding outlines derived from the font in a logo without re-licensing
the logo.
